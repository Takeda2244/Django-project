# Проект на фреймворке Django с помощью языка программирования Python

Этот проект рассматривает написание программы с помощью фреймворка Django

## Структура проекта

- `requirements.txt`: Список зависимостей.
- `python3 week01\day01\main.py`: Команда запуска проекта первого дня
- `python3 week01\day02\calculator.py`: Команда запуска проекта второго дня
- `python3 week01\day03\lists.py`: Команда запуска проекта третьего дня
- `python3 week01\day04\lists.py`: Команда запуска проекта четвертого дня

## Для задания пятого дня

## Установка

Для работы проекта и запуска тестов необходимо установить `pytest`. Выполните команду в терминале:

pip install pytest

## Запуск тестов

Для запуска тестов выполните команду из папки проекта:

python -m pytest week01/day05
